# 📝 DevTasks

> Aplicação web de gerenciamento de tarefas desenvolvida para praticar desenvolvimento Front-End, JavaScript e controle de versão com Git e GitHub.

## 🌐 Demonstração

🚀 **[Acessar o DevTasks online](https://mouramichel.github.io/devtasks/)**

## 🌐 Sobre o projeto

O **DevTasks** é uma aplicação de gerenciamento de tarefas criada com **HTML, CSS e JavaScript puro**.

O projeto foi desenvolvido como parte da minha jornada de aprendizado em programação, com foco na criação de uma aplicação funcional, organização de código e utilização do Git/GitHub para controle de versão.

## ✨ Funcionalidades

* ➕ Criar novas tarefas
* 🎯 Definir prioridade: baixa, média ou alta
* ✅ Marcar tarefas como concluídas
* 🗑️ Excluir tarefas
* 🔎 Filtrar tarefas por status
* 📊 Exibir quantidade de tarefas
* 💾 Salvar tarefas no navegador utilizando LocalStorage
* 📱 Interface responsiva

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/XxINSAN0xX/devtasks.git
```

### 2. Entre na pasta

```bash
cd devtasks
```

### 3. Execute

Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.
